# Security

Please don't report a security vulnerability in a public issue.

Report it privately instead: on this repository's **Security** tab, choose **Report a vulnerability**, or go to
<https://github.com/Liferay-Community-APAC/marketplace-app-docs/security/advisories/new>. Name the app and its
version, the Liferay DXP version, and how to reproduce the problem.

These are community apps, provided as-is. A vulnerability in Liferay DXP itself goes to Liferay:
<https://www.liferay.com/security>.
