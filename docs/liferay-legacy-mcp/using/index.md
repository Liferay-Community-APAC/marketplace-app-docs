# Using the Server

You don't call the tools yourself: you ask the AI assistant in plain language, and it picks the tools. These pages show what it can do, and how changes are kept safe.

{: .warning }
AI assistants can misread a request or pick the wrong item. Liferay Legacy MCP is for experimental use: try it on test content, keep writes off until you trust what you see, and read every preview before you confirm it.
